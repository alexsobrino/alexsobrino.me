# alexsobrino.me

Alex Sobrino's personal website: mainly a calling card, with a showcase of Side Projects and an optional stream of Notes.

## Language

**Note**:
A piece of writing published on the site, written as a single Markdown file. Notes come in one kind only, whatever their length.
_Avoid_: Post, Article, Entry

**Tag**:
A topic that a Note is substantially about, used to gather related Notes, such as every Note on one book. A Note has zero or more Tags, and only Notes carry them. Merely mentioning something doesn't earn a Note its Tag. A Tag is just a name: a book Tag carries no details of its own, and a Tag has no Content language.
_Avoid_: Category, Label

**Side Project**:
Something Alex has built independently and shows on the site. Each one has its own page and is featured on the home page with a picture, unlike Notes. Earning money doesn't make it something else; work done for an employer or client is not a Side Project.
_Avoid_: Project, Portfolio item, Work, Product

**Retired**:
A Side Project that no longer runs. It keeps its page and card, loses its outbound link and is labelled as retired instead of being removed.
_Avoid_: Archived, Dead, Discontinued

**Content language**:
The language a single Note or Side Project is written in. Each piece carries its own language, and translations of the same piece are not kept side by side.
_Avoid_: Locale, translation
